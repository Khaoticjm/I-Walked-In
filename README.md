# I Walked In — Landing Page

Landing page for *I Walked In: What Happened When My Mind Broke and My Body Became Evidence* by Jalisa Basnight.

A single static page: `index.html` plus the cover and author photo in `images/`. No build step.

## Before going live

Replace the placeholders in `index.html`: `[PAGE COUNT]`, `[PRICE]`, and and contact email (done).

## Publish with GitHub Pages

Live at https://iwalkedin.com (GitHub Pages, deployed from `main` / root; custom domain set in `CNAME`).
